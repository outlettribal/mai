Plugin base para WordPress con shortcode y página de ajustes.

== Description ==

Mi Plugin Hola crea un shortcode `[saludo_plugin]` que imprime un mensaje configurable.

== Installation ==

1. Copia la carpeta `mi-plugin-hola` dentro de `wp-content/plugins/`.
2. Activa **Mi Plugin Hola** desde el panel de plugins.
3. Ve a **Ajustes > Mi Plugin Hola** para configurar el mensaje.
4. Agrega `[saludo_plugin]` en cualquier entrada o página.
